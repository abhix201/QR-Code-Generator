# Security policy

## How data is handled

QR codes are generated entirely in your browser. The content you type is never sent to a server. Recent codes are stored in your browser's local storage on your device only, and Wi-Fi passwords are never stored.

## Reporting a vulnerability

Please email contact@abhijeetgupta0120.me with a description of the issue and steps to reproduce it. Please don't open a public GitHub issue for security problems. You can expect a reply within a week.
